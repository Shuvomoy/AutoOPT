# Interpolation Conditions Reference

## Notation

Each queried datum is \((x_i,g_i,f_i)\), where \(g_i\) is a subgradient, or the gradient when differentiability is imposed. For nonconvex rows, the regular-subgradient convention means \(g\in\hat\partial f(x)\), the regular (Fréchet) subdifferential: \(f(y)\ge f(x)+\langle g,y-x\rangle+o(\lVert y-x\rVert)\) as \(y\to x\); for proper lower-semicontinuous \(\rho\)-weakly convex functions the regular and limiting subdifferentials coincide. Inner products are \(\langle\cdot,\cdot\rangle\), and squared norms are \(\lVert\cdot\rVert^2\). The retained table below consists of full finite interpolation conditions under the stated assumptions; the convex, strongly convex, smooth, smooth (strongly) convex, and Lipschitz rows are the standard Taylor-Hendrickx-Glineur-type exact interpolation conditions. If a future user-supplied row is only necessary or sufficient, label that status explicitly and do not describe it as exact interpolation. For nonconvex rows, state the subdifferential convention and regularity assumptions before using the row. Do not infer unsupported function classes from nearby rows.

## Table of functions and retained conditions

| Function class | Retained condition |
|---|---|
| Convex functions | \(\forall i\ne j:\quad f_i-f_j\ge \langle g_j,x_i-x_j\rangle.\) |
| \(\mu\)-strongly convex functions | \(\mu\ge0,\quad \forall i\ne j:\quad f_i-f_j\ge \langle g_j,x_i-x_j\rangle+\frac{\mu}{2}\lVert x_i-x_j\rVert^2.\) |
| \(\rho\)-weakly convex functions with \(B\)-bounded regular subgradients | Literature-supported exact finite interpolation condition from Rubbens and Hendrickx, "A constraint-based approach to function interpolation, with application to performance estimation for weakly convex optimisation" (arXiv:2405.08405), for \(\rho>0,\ B\ge0\). Assume proper lower-semicontinuous \(\rho\)-weak convexity and \(g_i\in\partial f(x_i)\) under the regular-subgradient convention. For each ordered pair \(i\ne j\), introduce a witness \(C_{j,i}\in\mathbb R^d\) and impose \(\quad f_i-f_j\ge \langle g_j,x_i-x_j\rangle-\frac{\rho}{2}\lVert x_i-x_j\rVert^2+\frac{\rho}{2}\lVert x_i-C_{j,i}\rVert^2,\quad \lVert g_j+\rho(x_j-C_{j,i})\rVert^2\le B^2,\quad \lVert g_j\rVert^2\le B^2.\) Equivalently, \(C_{j,i}\) is a projection-compatible witness for the ball centered at \(x_j+g_j/\rho\) with radius \(B/\rho\). For \(\rho=0\), use the \(M\)-Lipschitz convex row with \(M=B\). |
| \(L\)-smooth functions | \(0<L<\infty,\quad \forall i\ne j:\quad f_i-f_j\ge \frac12\langle g_i+g_j,x_i-x_j\rangle+\frac{1}{4L}\lVert g_i-g_j\rVert^2-\frac{L}{4}\lVert x_i-x_j\rVert^2.\) |
| \(L\)-smooth convex functions | \(0<L<\infty,\quad \forall i\ne j:\quad f_i-f_j\ge \langle g_j,x_i-x_j\rangle+\frac{1}{2L}\lVert g_i-g_j\rVert^2.\) |
| \((\mu,L)\)-smooth strongly convex functions | \(0\le\mu<L<\infty,\quad \forall i\ne j:\quad f_i-f_j\ge \langle g_j,x_i-x_j\rangle+\frac{1}{2L}\lVert g_i-g_j\rVert^2+\frac{\mu}{2(1-\mu/L)}\left\lVert x_i-x_j-\frac1L(g_i-g_j)\right\rVert^2.\) |
| \(M\)-Lipschitz convex functions | \(M\ge0,\quad \forall i:\ \lVert g_i\rVert^2\le M^2,\qquad \forall i\ne j:\ f_i-f_j\ge \langle g_j,x_i-x_j\rangle.\) |
| \((L,M)\)-smooth Lipschitz convex functions | \(0<L<\infty,\ M\ge0,\quad \forall i:\ \lVert g_i\rVert^2\le M^2,\qquad \forall i\ne j:\ f_i-f_j\ge \langle g_j,x_i-x_j\rangle+\frac{1}{2L}\lVert g_i-g_j\rVert^2.\) Exactness of this conjunction for the intersection class holds by Lipschitz regularization of an \(L\)-smooth convex interpolant (infimal convolution \(f_0\,\square\,M\lVert\cdot\rVert\) preserves \(L\)-smooth convexity and the interpolation data when \(\lVert g_i\rVert\le M\)); provenance label: proved in-session. |
| Closed convex indicator functions with diameter \(D\) and radius \(R\) | \(D,R\in[0,\infty],\quad \forall i:\ f_i=0,\qquad \forall i\ne j:\ \langle g_j,x_i-x_j\rangle\le0.\quad D<\infty\Rightarrow \forall i,j:\ \lVert x_i-x_j\rVert^2\le D^2.\quad R<\infty\Rightarrow \exists c\ \forall i:\ \lVert x_i-c\rVert^2\le R^2\), with \(c\) fixed if specified and otherwise free; treat a free \(c\) as an additional Gramian basis (witness) column. |
| Convex support functions with Lipschitz bound \(M\) | \(M\in[0,\infty],\quad \forall i:\ f_i=\langle g_i,x_i\rangle,\qquad M<\infty\Rightarrow \forall i:\ \lVert g_i\rVert^2\le M^2,\qquad \forall i\ne j:\ \langle x_j,g_i-g_j\rangle\le0.\) |
